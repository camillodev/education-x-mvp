# Official Docs First

## Quando usar

Use quando o usuario pedir:
- setup de ferramenta
- mudanca de configuracao
- sugestao de arquitetura
- recomendacao tecnica com possiveis alternativas

## Fluxo obrigatorio

1. Mapear contexto real do projeto/ambiente antes de sugerir mudanca.
2. Identificar e consultar a documentacao oficial da tecnologia envolvida.
3. So depois recomendar a opcao, com justificativa curta.

## Regras de resposta

- Priorizar docs oficiais sobre blog, forum ou tutorial.
- Se houver conflito entre pratica comum e doc oficial, dizer isso claramente e recomendar o oficial.
- Nao sugerir sem evidencia minima (arquivo, config, comando ou trecho de doc).
- Entregar resposta objetiva: causa raiz -> recomendacao -> proximo passo.
